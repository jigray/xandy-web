# xandy-web

**잔디학원 (대치동 물리 전문 학원) 공식 홈페이지 재구축 프로젝트**

현재 아임웹으로 운영 중인 [xandy.co.kr](https://www.xandy.co.kr)을 Next.js 기반으로 완전히 재디자인하면서 **기존 SEO 자산은 최대한 보존**하는 것을 목표로 합니다.

## 스택

- **Next.js** (App Router)
- **Node.js**
- 개발 환경: macOS (Mac mini)

## 현재 단계

🔵 **기획 (Planning)** — 디자인 및 UX 설계 중
⚪ 디자인 (Design)
⚪ 구현 (Implementation)
⚪ 배포 (Deploy)
