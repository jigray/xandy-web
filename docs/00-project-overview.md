# 00. 프로젝트 개요

## 왜 재구축하는가?

현재 **잔디학원** 홈페이지는 아임웹(imweb) 플랫폼으로 운영되고 있습니다. SEO/GEO(지역 검색)는 어느 정도 잘 잡혀 있지만, 다음과 같은 문제가 있습니다:

1. **시간표 구조가 실제 수업 패턴과 맞지 않음** — 월~일 7일 격자지만 실제는 **주말 중심 + 대회 시즌 평일**
2. **H1 태그가 비어 있는 등 SEO 기본기 미비** — 아임웹 템플릿 한계
3. **JSON-LD 스키마 타입이 잘못됨** — `OnlineStore` → `EducationalOrganization`이 맞음
4. **디자인 자유도 부족** — 커스터마이징이 템플릿 수준에 머물러 있음
5. **코드 소유권/확장성** — 아임웹 종속 상태

## 목표

- Next.js (App Router) 기반으로 **완전 재디자인**
- **기존 SEO 랭킹은 유지** 또는 개선
- **주말 중심 수업 UX**를 직관적으로 표현
- **물리대회 시즌의 평일 수업**도 자연스럽게 통합
- 각 수업의 **회차** 정보를 명확히 노출

## SEO 전략 (핵심)

> **URL 구조는 가능한 한 그대로 유지한다.**
> URL이 바뀌면 리다이렉트가 복잡해지고 랭킹 유실 위험이 커진다.

- 기존 22개 URL은 그대로 유지 (상세는 [02-url-structure.md](02-url-structure.md))
- 메타태그, 키워드 세트, 사이트 인증 코드 **그대로 이전**
- JSON-LD는 **`EducationalOrganization` + `LocalBusiness`** 타입으로 교체 (아임웹 기본값 `OnlineStore`는 부적절)
- 네이버/구글/빙 사이트 인증 메타태그 유지

## 범위에서 제외하는 것 (YAGNI)

- 로그인/회원 시스템 (아임웹에선 있지만, 신규 사이트에선 **일단 제외**)
- 결제/쇼핑 (`/shop_view/*`) — 교재 판매는 **별도 결정** 필요
- 다국어
- 블로그/CMS (공지사항은 어떻게 할지 별도 논의 필요)

## 핵심 디자인 결정 (대기 중)

- [ ] 홈 화면의 1순위 콘텐츠 (학부모 페르소나에 따라 다름)
- [ ] 시간표 UI 패턴 (주말 2일 뷰 vs 월 전체 뷰 vs 하이브리드)
- [ ] 회차 표기 방식
- [ ] 물리대회 시즌 평일 노출 방식
- [ ] 공지사항 운영 방식 (CMS? MDX? 수동?)
- [ ] 교재 판매 유지 여부
